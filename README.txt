CEI Pro v2 - Home Dashboard Module

Files included:
- index.html
- styles.css
- app.js
- manifest.json
- sw.js
- icon-192.svg
- icon-512.svg

How to deploy on Netlify:
1. Unzip this package.
2. Drag the extracted folder contents into your Netlify site deploy area.
3. If replacing your current CEI PWA, upload these files over the old files.
4. Open the Netlify URL on your iPhone in Safari.
5. Use Share > Add to Home Screen.

What this module includes:
- Mobile-first CEI Home Dashboard
- CDEI score and status
- Executive level and points
- Prediction accuracy and streak tracking
- Weekly checklist and completion bar
- Leadership talking points
- Top 5 signals
- Chilliwack development snapshot
- Achievements
- Quick capture panel
- JSON export/import backup
- PWA manifest and service worker

Data storage:
- Data is stored locally in browser localStorage.
- Export JSON before replacing files or switching devices.
